# cut_clips
A tool to cut video clips, translate subtitles, and generate TSV files ready for Anki import.

This tool is designed to streamline language learning through video content. The program processes a video file to cut specific clips, automatically translate their subtitles, and generate a .tsv file ready to import into Anki, allowing you to create study flashcards with audio and text in just a few seconds.

Key Features:
- Precise video and audio clip cutting.
- Automated subtitle translation into your target language.
- Direct export to Anki-compatible TSV format.
