# Fase 12.2 — Reproducción mpv embebida en la GUI

**Fecha:** 2026-09-21

## Problema

Tras la Fase 12.1 (fix `LC_NUMERIC`), la app ya no crashea al abrir vídeo, pero el reproductor aparecía en una **ventana mpv externa** en lugar del panel negro de la GUI. Los controles Play/Pause/Stop respondían mal o no afectaban al vídeo visible.

## Diagnóstico

| Aspecto | Antes de 12.1 (`52bafe6`) | Después de 12.1 | ¿Cambió? |
|---------|---------------------------|-----------------|----------|
| Widget vídeo | `QFrame` sin atributos nativos | Igual | **No** |
| Embed mpv | `wid=winId()`, `vo=gpu` | Igual | **No** |
| Locale | Sin `_ensure_mpv_numeric_locale()` | Añadido | Sí (12.1) |

**Conclusión:** La Fase 12.1 **no alteró** el embedding. Solo permitió llegar a `mpv.MPV(...)`. El problema de ventana externa es **preexistente**, expuesto al corregir el SIGSEGV.

### Causa raíz (Wayland)

En sesiones **Wayland**, libmpv documenta que **`wid` no funciona** en compositor Wayland nativo ([mpv#9654](https://github.com/mpv-player/mpv/issues/9654)). La alternativa oficial es la **Render API** (OpenGL).

Factores agravantes:

1. `QFrame` sin `WA_NativeWindow` / `WA_DontCreateNativeAncestors` — el `winId()` puede no ser válido para embed ([python-mpv README](https://github.com/jaseg/python-mpv)).
2. Crear mpv inmediatamente tras el diálogo OK, antes de que Qt materialice la ventana nativa del widget.
3. `vo=gpu` en lugar de `vo=x11` bajo X11/XWayland.

### PipeWire y cierre

| Síntoma | Relación con embed |
|---------|-------------------|
| `pw.conf can't load client.conf` | **Independiente** — warning al abrir audio |
| `KeyboardInterrupt` en `closeEvent` | Cierre mpv bloqueante; mejorado con `_shutdown_mpv_player()` |

## Solución (enfoque híbrido)

### Capa 1 — QFrame + `wid` (XWayland)

Cuando `XDG_SESSION_TYPE=wayland` y existe `DISPLAY` (XWayland):

1. Antes de `QApplication`: `QT_QPA_PLATFORM=xcb` (solo el proceso Python).
2. Atributos en `video_frame`: `WA_DontCreateNativeAncestors`, `WA_NativeWindow`.
3. Init diferida: `QTimer.singleShot(0, _deferred_load_media_in_player)` si el `QFrame` aún no tiene ventana nativa.
4. `vo=x11` si la plataforma Qt efectiva es `xcb`.

### Capa 2 — `MpvGlWidget` (Wayland nativo)

Módulo `ui/mpv_gl_widget.py`: `QOpenGLWidget` + `mpv.MPV(vo="libmpv")` + `MpvRenderContext` OpenGL.

Se activa cuando:

- Wayland **sin** `DISPLAY` (sin XWayland), o
- Plataforma Qt efectiva es `wayland`, o
- `ANKI_FORCE_MPV_GL=1`.

Forzar Capa 1: `ANKI_FORCE_MPV_WID=1`.

### Cierre limpio

`_shutdown_mpv_player()`:

1. Detiene timer de posición y A-B loop.
2. Pausa mpv, `command("stop")`, desactiva `ab_loop_a` / `ab_loop_b`.
3. Capa 1: `wid=0` para desvincular X11, `processEvents()`, luego `terminate()`.
4. Capa 2: `render_ctx.free()` y `terminate()`.

Llamado **solo** desde `closeEvent` (tras prompt de guardar). Al cambiar de vídeo o cargar proyecto se reutiliza la misma instancia con `loadfile` (sin `terminate()`).

## Cómo probar

```bash
python3 gui_app.py
# Archivo → Abrir vídeo → OK
# El vídeo debe verse DENTRO del panel negro, no en ventana externa
# La lista «Oraciones pendientes» se rellena automáticamente si hay:
#   - un .srt junto al vídeo (mismo nombre), o
#   - una pista de subtítulos textual embebida seleccionada en el diálogo ffprobe
# Play / Pause / Stop / Probar clip / Cerrar app
```

Variables de entorno útiles:

```bash
# Forzar Render API OpenGL (Capa 2)
ANKI_FORCE_MPV_GL=1 python3 gui_app.py

# Forzar wid + xcb (Capa 1) — recomendado en Wayland + XWayland
ANKI_FORCE_MPV_WID=1 python3 gui_app.py

# Decodificación solo software si auto-safe falla
ANKI_MPV_HWDEC=no python3 gui_app.py

# Salida de audio (default: pulse,pipewire,alsa)
ANKI_MPV_AO=alsa python3 gui_app.py
```

| Variable | Default | Uso |
|----------|---------|-----|
| `ANKI_MPV_AO` | `pulse,pipewire,alsa` | Forzar driver de audio si el default falla |

### Avisos de consola (no bloquean el vídeo)

| Mensaje | Causa | Acción |
|---------|-------|--------|
| `Audio output auto not found` | `ao=auto` no resuelve driver | Corregido: `ao=pulse,pipewire,alsa` por defecto |
| `Cannot load libcuda.so.1` | mpv/Qt prueban CUDA/NVDEC sin drivers NVIDIA | `hwdec=auto-safe` (por defecto) o `ANKI_MPV_HWDEC=no` |
| `pw.conf can't load client.conf` | Config PipeWire del sistema ausente | `PIPEWIRE_LOG=0` al arrancar; no afecta render |

Comprobación rápida de imports y locale:

```bash
python3 -X faulthandler -c "

print('platform cfg ok')

```
